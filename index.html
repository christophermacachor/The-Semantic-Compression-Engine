1. Formal BNF grammar for the token language

<file>              ::= <statement-list>

<statement-list>    ::= <statement>
                       | <statement> <statement-list>

<statement>         ::= <token>
                       | <token> <separator> <statement>

<separator>         ::= "." | ";" | "," | ":" | "?" | "!"

<token>             ::= <absolute-token>
                       | <derivation-token>
                       | <information-token>
                       | <placeholder-token>
                       | <encoding-token>
                       | <operator-token>
                       | <particle-token>

<absolute-token>    ::= "ABSOLUTE" | <absolute-lexeme>
<derivation-token>  ::= "DERIVATION" | <derivation-lexeme>
<information-token> ::= "INFORMATION" | <information-lexeme>
<placeholder-token> ::= "PLACEHOLDER" | <placeholder-lexeme>
<encoding-token>    ::= "ENCODING" | <encoding-lexeme>

<operator-token>    ::= "of" | "and" | "or" | "not"
                       | "=>" | "<=>" | "+" | "-" | "*" | "/"

<particle-token>    ::= "the" | "a" | "an" | "this" | "that"

<absolute-lexeme>    ::= /* irreducible terms, e.g. "energy", "scalar", "R" */
<derivation-lexeme>  ::= /* operations from C0, e.g. "derive", "map", "integrate" */
<information-lexeme> ::= /* structures, e.g. "system", "configuration" */
<placeholder-lexeme> ::= /* signs, e.g. "equation", "model" */
<encoding-lexeme>    ::= /* welds/encodings, e.g. "formula", "notation" */

Validity test function (semantic layer over BNF)

CATEGORY ::= C0 | C1 | C2 | C3 | C4 | U ;

VALIDITY_TEST(t) ::=
      (t.decidable == false)                => U
    | (t.irreducible == true)               => C0
    | (t.names_operation_from_C0 == true)   => C1
    | (t.recoverable_structure == true)     => C2
    | (t.encoding_of_C3 == true)            => C4
    |                                       => C3 ;

2. Deterministic cancellation automaton

States:
  q_start  – initial
  q_run    – processing tokens
  q_halt   – halting on UNDECIDABLE

Input alphabet Σ:
  all <token> instances from the BNF grammar.

Output:
  compressed form (C0/C1/C2 tokens in order)
  nullification log (events for C3/C4)

Transition function δ:
  δ(q_start, t) = q_run
  δ(q_run,   t) =
      if VALIDITY_TEST(t) == U:
          q_halt
      else:
          q_run
  δ(q_halt,  t) = q_halt

Output function λ at q_run:
  c = VALIDITY_TEST(t)

  if c ∈ {C0, C1, C2}:
      emit_compressed(t)

  if c ∈ {C3, C4}:
      emit_nullification_event(t)

  if c == U:
      // no output; engine halts

NULLIFICATION_EVENT:
  token: <t.lexeme>
  claimed_category: <t.claims>
  assigned_category: <C3 | C4>
  rule_violated: <DDL | PL-3 | PL-4 | PL-6 | PL-6.1>
  reason: <string>
  timestamp: <UTC>
  hash_of_input: <SHA-256>

3. Byte-level deterministic validator (registration-grade)

Invariant:
  "The canonical file is stored with no trailing newline,
   and is hashed byte-for-byte as stored."

Input:
  byte stream B[0..N-1] of the canonical file.

States:
  S_START   – before any byte
  S_BODY    – reading body bytes
  S_SEEN_LAST – after last byte
  S_ERROR   – violation
  S_DONE    – successful validation

Validator DFA:

  state = S_START
  sha256_ctx = init_sha256()

  for i from 0 to N-1:
      b = B[i]

      if state == S_START:
          state = S_BODY

      if state == S_BODY:
          update_sha256(sha256_ctx, b)

  if N == 0:
      state = S_ERROR
  else:
      state = S_SEEN_LAST
      last_byte = B[N-1]

  if state == S_SEEN_LAST:
      if last_byte == 0x0A:        // LF newline
          state = S_ERROR          // trailing newline violation
      else:
          computed_hash = finalize_sha256(sha256_ctx)
          // compare with stored hash in registration record
          if computed_hash != stored_hash_in_manifest:
              state = S_ERROR
          else:
              state = S_DONE
